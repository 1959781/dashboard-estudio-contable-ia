# 📊 Sistema de Automatización para Estudio Contable con IA

## 📝 Descripción del Proyecto
Este es el proyecto final de la carrera. Consiste en un panel principal (Dashboard) centralizado que servirá como estudio virtual e irá integrando automatizaciones por submódulos de forma paulatina.

## 🎯 Estructura del Tablero Principal
El sistema contendrá los siguientes subtableros integrados:
* **Clasificación:** Módulo inteligente para clasificar automáticamente los documentos recibidos con IA.
* **Legales y Actas:** Automatización de actas mediante el uso de formularios clásicos requeridos.
* **Impuestos:** Control impositivo y liquidación de IVA e Ingresos Brutos (se integrará gradualmente según los tiempos de entrega).
